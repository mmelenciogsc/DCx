# Browser keyboard shortcuts

These shortcuts follow common desktop-browser conventions and apply while the DCx window has focus.

| Shortcut | Action |
|---|---|
| `Ctrl+L` | Focus and select the web address. |
| `Ctrl+T` | Open a new tab in the selected new-tab profile. |
| `Ctrl+W` | Close the selected tab. A replacement opens if it was the final tab. |
| `Ctrl+Tab` | Move to the next browser tab. |
| `Ctrl+D` | Bookmark the current page. |
| `Ctrl+H` | Open browsing history. |
| `Ctrl+J` | Open downloads. |
| `Alt+Left` | Go back. |
| `Alt+Right` | Go forward. |
| `F6` | Cycle focus among the address bar, live page, and Agent button. |
| `Escape` | Close the open information panel or Agent drawer. |

DCx does not register system-wide hotkeys. These keystrokes are handled only while its window is focused. Human JAWS/NVDA/Narrator conflict testing remains required.

## Local dependency transfer access keys

These window-local access keys are available only in **Local models**. Approval starts unchecked.

| Shortcut | Action |
|---|---|
| `Alt+O` | Explicitly observe current public provider routes with HEAD requests only; this does not approve payload transfer. |
| `Alt+K` | Cancel the active provider-route review. |
| `Alt+B` | Begin the separately approved exact-plan dependency transfer. |
| `Alt+C` | Cancel the active transfer and clean its incomplete private state. |
| `Alt+V` | Reverify the protected completed transfer set. |
| `Alt+R` | Recover strict abandoned partial-transfer directories under the DCx data lease. |

Route observation creates only a non-persisted two-hour exact query-free review. Payload approval remains separately unchecked. These actions do not install, register, select or execute transferred content. Human JAWS/NVDA/Narrator conflict testing remains required.

## Release readiness privacy access keys

These window-local keys are available only in **Release readiness**. Both approvals start unchecked and reset after use.

| Shortcut | Action |
|---|---|
| `Alt+I` | Check or clear the local aggregate-recording consent. |
| `Alt+E` | Enable local aggregate recording after consent. This connects no event source or transport. |
| `Alt+A` | Check or clear the separate permanent-purge acknowledgment. |
| `Alt+S` | Stop local recording and permanently purge retained aggregate buckets after acknowledgment. |
| `Alt+R` | Refresh the read-only release decision, blockers, metric definitions and local consent state. |

No key enrolls a pilot, sends metrics or activates production. Human JAWS/NVDA/Narrator conflict testing remains required.
