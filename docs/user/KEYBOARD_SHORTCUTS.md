# Browser keyboard shortcuts

These shortcuts follow common desktop-browser conventions and apply while the DCx window has focus.

| Shortcut | Action |
|---|---|
| `Ctrl+L` | Focus and select the web address. |
| `Ctrl+T` | Open a new tab in the selected new-tab profile. |
| `Ctrl+W` | Close the selected tab. A replacement opens if it was the final tab. |
| `Ctrl+Tab` | Move to the next browser tab. |
| `Ctrl+D` | Bookmark the current page. |
| `Ctrl+H` | Open browsing history. |
| `Ctrl+J` | Open downloads. |
| `Alt+Left` | Go back. |
| `Alt+Right` | Go forward. |
| `F6` | Cycle focus among the address bar, live page, and Agent button. |
| `Escape` | Close the open information panel or Agent drawer. |

DCx does not register system-wide hotkeys. These keystrokes are handled only while its window is focused. Human JAWS/NVDA/Narrator conflict testing remains required.
