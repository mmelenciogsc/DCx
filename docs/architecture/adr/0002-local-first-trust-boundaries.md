# ADR 0002: Local-first execution and broker boundaries

- Status: Accepted
- Date: 2026-10-17

DCx keeps routine orchestration, browser profiles, files, prompts, private knowledge, model processes, and OS automation on the user's Windows device. All operating-system effects pass through typed least-privilege brokers with allowlists, budgets, cancellation, provenance, and accessible confirmations. Web/document/model output is data, never authority. Remote providers and the global service receive only task-approved payloads. Elevation, installs, publishing, payments, and destructive actions require a fresh explicit approval.
