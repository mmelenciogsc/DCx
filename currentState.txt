## Latest P13 work

The latest implementation is read-only backup verification (`7ff6387`, documented by `69936dc` and ADR 0121). Recovery can verify a selected backup with `Alt+V` while the live app owns its lease. The strict verification writes nothing, leaves archive and data unchanged, and grants no return authority. The earlier one-use recovery return path (`Alt+T`) still requires a successful backup or restore. This is recovery hardening only; it is not approval for package, installer, uninstall, update, signing, or production backup policy work.

P13 still requires all of the following before it can be called complete:

- owner-approved production identity/certificate and signing custody;
- genuinely signed DCx MSIX and revalidation immediately before lifecycle actions;
- approved lifecycle coordinator plus accessible install/relaunch/upgrade/rollback/uninstall on a clean Windows 11 VM;
- independent security assessment; and
- human JAWS, NVDA, and Narrator acceptance.

Do not sign, install, activate, uninstall, restart, publish, deploy, enroll users, or alter external services without explicit owner approval.
